Compare any two legendary album covers side-by-side. Inspect their visual artwork, rankings, ratings, and era contrasts.

Cool Feature: The DJ Sonic Crossfader

Slide between both album artworks to examine visual contrast and composition.

viewof crossfadeVal = Inputs.range([0, 100], {
  label: "DJ Crossfade (A ◄► B)",
  value: 50,
  step: 1
})
// Interactive DJ Morph / Crossfader Screen
html`
<div style="position: relative; width: 100%; max-width: 440px; height: 380px; margin: 1.5rem auto; border-radius: 18px; overflow: hidden; border: 2px solid #00f2fe; box-shadow: 0 0 30px rgba(0, 242, 254, 0.25); background: #000;">
  <!-- Album A layer -->
  <img 
    src="${albumA_choice.image_url}" 
    referrerpolicy="no-referrer"
    crossorigin="anonymous"
    style="position: absolute; top: 0; left: 0; width: 100%; height: 100%; object-fit: cover; opacity: ${1 - crossfadeVal / 100}; transition: opacity 0.05s ease;" 
  />

  <!-- Album B layer -->
  <img 
    src="${albumB_choice.image_url}" 
    referrerpolicy="no-referrer"
    crossorigin="anonymous"
    style="position: absolute; top: 0; left: 0; width: 100%; height: 100%; object-fit: cover; opacity: ${crossfadeVal / 100}; transition: opacity 0.05s ease;" 
  />

  <!-- Crossfade overlay label -->
  <div style="position: absolute; bottom: 12px; left: 12px; right: 12px; background: rgba(0,0,0,0.75); backdrop-filter: blur(8px); padding: 8px 14px; border-radius: 8px; display: flex; justify-content: space-between; font-size: 0.8rem; font-weight: bold; color: #fff;">
    <span style="color: #00f2fe;">${100 - crossfadeVal}% ${albumA_choice.album}</span>
    <span style="color: #ffd166;">${crossfadeVal}% ${albumB_choice.album}</span>
  </div>
</div>
`
